# BarGlyph

A Swift package for generating 1D & 2D barcode images.

## Requirements

- Swift 6.2+
- macOS 26+ / iOS 26+

## Installation

Add BarGlyph to your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/<owner>/BarGlyph.git", from: "0.1.0")
]
```
